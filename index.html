Чем проверено

Каждый кейс заканчивается запуском с кодом возврата. У ОСВ и демо операций это 4 при расхождении, у проверки вакансий 4 при найденном контакте или дубле. Числа на страницах взяты из этих прогонов.

Тесты шести проектов идут в GitHub Actions на каждый push; последние прогоны зелёные у всех шести. Те же тесты можно запустить локально: python -m unittest discover -s tests в каталоге проекта.

Книги Excel проверены штатным валидатором: 0 ошибок, 0 предупреждений линтера. Страницы проверены статическим чекером и рендером на ширинах 1440 и 390 пикселей, переполнения нет.

Чего здесь нет

Ни один кейс не проверен на данных заказчика. ОСВ и демо операций построены на синтетике: компания, контрагенты и суммы вымышлены. Вакансии взяты из открытой выгрузки, но она неполная: шесть запросов по сто строк.

Excel не открывался. Формулы в книгах записаны корректно, но движок их не пересчитывал. Контрольные суммы сверены скриптом с исходными CSV, поэтому книга и расчёт разойдутся только при ошибке в формуле, а её никто не считал.

Проверка ОСВ не знает учётной политики: неверная корреспонденция счетов сойдётся по сальдо и останется незамеченной. Проверка вакансий исключает контакты по колонкам и регулярке, но не гарантирует, что в названии работодателя нет фамилии. Поэтому списка работодателей на странице нет.

Как перепроверить

ОСВ: python check_osv.py --dir data. Код 0, если найденный набор совпал с заложенным.

Вакансии: python check_jobs.py --dir data. Код 0, если в таблице нет контактов, дублей и расхождений с разрезами.

Операции: python demo.py. Код 0, если все девять сверок сошлись.
