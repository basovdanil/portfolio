Три операции, которые раньше делались мышью

Слить несколько выгрузок в один реестр, найти отличия между версиями таблицы, разложить файл по папкам. На каждую операцию одна команда и отчёт в JSON. Демо прогоняет все три на 72 строках и сверяет результат с заранее посчитанным.

Операции

Команды, которые запускаются на входных файлах демо.

  1. Слить выгрузки
    Несколько файлов с одним реестром сводятся в один, повторы по ключу отбрасываются.
    tables.py merge --inputs reg-01.csv reg-02.csv --key id --out v1.csv
  2. Сравнить версии
    Две версии таблицы дают список добавленных, удалённых и изменённых строк.
    tables.py diff --old v1.csv --new v2.csv --key id --out diff.csv
  3. Разложить по папкам
    Один файл делится на части по значению колонки, рядом кладётся манифест.
    tables.py split --input v2.csv --by склад --outdir parts

Границы

При слиянии побеждает первая встреченная строка: порядок файлов в команде задаёт приоритет. Если нужно «последняя версия важнее», это другой режим, и его здесь нет.

Сравнение идёт по строкам как по тексту: «1000» и «1000.0» будут показаны как изменение, хотя число то же. Перед сравнением выгрузки надо приводить к одному формату.

Демо работает на синтетике: вымышленные контрагенты и склады. Скрипт не проверялся на файлах из 1С: там встречаются шапки в несколько строк и объединённые ячейки, а такого режима у него нет.
