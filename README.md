# portfolio

[![checks](https://github.com/basovdanil/portfolio/actions/workflows/checks.yml/badge.svg)](https://github.com/basovdanil/portfolio/actions/workflows/checks.yml)

Три разобранных кейса с кодом, данными и проверкой: https://basovdanil.github.io/portfolio/

Каждая страница — статический HTML, данные и скрипты лежат рядом, поэтому любую
цифру со страницы можно пересчитать локально.

## Что внутри

| Каталог | Страница | Данные | Проверка |
|:--|:--|:--|:--|
| `case-osv/` | [ОСВ: пять дефектов](case-osv/case-osv.html) | `data/osv.csv` (синтетика), `data/meta.json` | `check_osv.py` |
| `case-jobs/` | [Вакансии: ноль контактов](case-jobs/case-jobs.html) | `data/jobs.csv` (только открытые поля), `data/by_*.csv` | `check_jobs.py` |
| `case-tables/` | [Три операции скриптом](case-tables/case-tables.html) | `work/in/*.csv` (синтетика) | `demo.py` |

`index.html` — точка входа со сводной таблицей кейсов.

## Как проверить

Скрипты читают пути относительно текущего каталога, поэтому запускать из
каталога кейса. Нужен только Python 3.9+, внешних зависимостей нет.

```bash
cd case-osv    && python check_osv.py      # 0 — набор находок совпал с ожидаемым
cd case-jobs   && python check_jobs.py     # 0 — почт и телефонов нет, дублей нет
cd case-tables && python demo.py           # 0 — все сверки сошлись
```

Коды возврата у всех проверок одинаковые: `0` — всё сошлось, `2` — аргументы,
`3` — нет входных файлов, `4` — найдено расхождение.

Те же три команды запускаются в GitHub Actions на каждый push — Python 3.9, 3.11
и 3.13; бейдж в шапке показывает последний прогон.

Что именно проверяет каждый скрипт:

- `check_osv.py` — пересчитывает итоги и арифметику каждой строки из CSV и сверяет
  найденные дефекты с `meta.json`; дефекты заложены в данные генератором `gen_osv.py`.
- `check_jobs.py` — белый список полей (никаких ФИО, телефонов и почт), дубли по id,
  сходимость разрезов с итогом.
- `demo.py` — строит входные файлы, гоняет `tables.py merge/diff/split` и сверяет
  количество строк на каждом шаге.

## Пересборка страниц и книг

HTML и `.xlsx` собираются скриптами `case-*/…build.cjs`, которым нужен каталог
`SKILLS_DIR` с утилитами для ExcelJS. Это локальный инструмент автора, в
репозиторий он не входит: данные и проверки воспроизводятся без него, сборка
артефактов — нет.
